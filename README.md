# agent-indicator

Физический пульт на 4 агента Claude Code. Подключается к маку по USB-C.
Плоская коробка с сеткой 4 × 4, как у стримерского пульта; лежит плашмя или стоит на откидных ножках:
столбец — один агент, три огня сверху вниз (красный / жёлтый / зелёный) плюс
кнопка. Нажатие на кнопку фокусирует окно терминала с этим агентом.

```
         ╱───────────────────────────────╲
        ╱   ●     ●     ●     ●           ╲   красный  — нужен ввод
       ╱    ●     ●     ●     ●            ╲  жёлтый   — думает
      ╱     ●     ●     ●     ●             ╲ зелёный  — готов к вводу
     ╱    ┌───┐ ┌───┐ ┌───┐ ┌───┐            ╲
    ╱     │ 1 │ │ 2 │ │ 3 │ │ 4 │             ╲ кнопка  — открыть терминал
   ╱      └───┘ └───┘ └───┘ └───┘              ╲
  └────────────────────────────────────────────┘
```

Габарит ~97 × 60 × 85 мм, две печатные детали, всё на одной плате.

## Семантика

| Состояние агента | Свет | Событие-триггер |
|---|---|---|
| думает / работает инструментами | 🟡 жёлтый | `UserPromptSubmit`, `PreToolUse`, `PostToolUse` |
| требуется ввод (разрешение, вопрос) | 🔴 красный | `PermissionRequest`, `Notification(permission_prompt / agent_needs_input)`, `Elicitation` |
| ничего не делает, готов к вводу | 🟢 зелёный | `Stop`, `Notification(agent_completed)` |
| агент не подключён | ⚫ не горит | `SessionEnd`, таймаут, смерть демона |
| подключение | приветственная анимация | `SessionStart` |

## Состав системы

```
┌──────────────────────┐
│  Claude Code #1..#N  │  hooks (http + command)
└──────────┬───────────┘
           │ POST http://127.0.0.1:48879/hook
┌──────────▼───────────────────────────────────┐
│  agentlightd  (Swift, LaunchAgent)           │
│   • HTTP-сервер для хуков                    │
│   • аллокатор слотов session_id → 0..N-1     │
│   • стейт-машина на слот                     │
│   • фокус окна терминала (AppleScript / AX)  │
└──────────┬───────────────────────────────────┘
           │ USB-C: HID-репорты (+ CDC для логов)
┌──────────▼───────────────────────────────────┐
│  RP2040 firmware                             │
│   • 12 LED (4 × R/Y/G), 14-битный PWM        │
│   • 4 кнопки, дебаунс, press                 │
│   • анимации, гамма, калибровка цветов       │
│   • watchdog: нет heartbeat → всё гаснет     │
└──────────────────────────────────────────────┘
```

## Начать отсюда

1. [docs/07-assembly.md §7.2](docs/07-assembly.md#72-что-купить-этап-макетки-m1m5) →
   заказать детали для макетки (~$100 с инструментами). Паяльник не нужен.
2. Пока едут — M4–M5 (софт для мака) делаются без железа: `--fake-device` и светофоры в строке меню.
   **Готово 2026-10-16**, установка — [host/README.md](host/README.md).
3. Этапы M1–M5 проходятся на макетной плате без единой пайки. Решение про
   пайку — только на M6, и для неё есть три пути, включая «отдать на сборку».
